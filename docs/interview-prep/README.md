## How to Use This Guide

1. **Start with** [10_study_guide.md](10_study_guide.md) — it tells you what to study first based on priority.
2. **Read each document** in order (1 → 9) for full understanding.
3. **Each document ends with** a section of **probable interview questions and strong answers**.
4. **Practice explaining** each concept aloud — interviewers value articulation as much as knowledge.
